# Telegram music bot

Бот ищет до пяти вариантов на YouTube. После нажатия на вариант он загружает аудио и отправляет его в чат.

## Запуск в Windows PowerShell

1. Отзови старый токен через BotFather и создай новый.
2. Установи Python-пакеты: `py -m pip install -r requirements.txt`
3. Установи FFmpeg и добавь его в `PATH` (он нужен для преобразования аудио в MP3).
4. Задай новый токен в текущем окне PowerShell: `$env:BOT_TOKEN="НОВЫЙ_ТОКЕН"`
5. Запусти бота: `py telegrammusic.py`

Для работы бота окно PowerShell должно оставаться открытым. Используй загрузку только материалов, на которые у тебя есть права или разрешение на скачивание.
